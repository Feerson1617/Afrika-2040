## Nachweisgrenzen

Alle 52 Varianten sind intern prüfbare Lernwege, keine empirisch nachgewiesene Lernwirkung. Das Spiel ersetzt weder Unterrichtsgespräch noch Diagnose individuellen Vorwissens. Insbesondere AHR enthält mehrere kurze Erkläranlässe über verschiedene Falluntersuchungen; sie sollen nicht als ein langer Aufsatz abgearbeitet werden. Lehrkraft-/Partnerkontrolle ist eine eigene, hier nicht automatisch als erfolgt verbuchte Handlung. Vollständige historische Schülertexte werden nicht in neue Profile umgedeutet. Kein fertiges Prüfungsblatt oder Notenschlüssel.
